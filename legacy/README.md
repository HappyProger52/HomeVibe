# Предыдущая версия на Node.js

Здесь сохранён прежний сервер как материал для сравнения. Это архив исходников, он больше не используется при запуске сайта. Страницы перенесены в `src/main/resources/static` и работают с Java API. Запускать проект нужно через Maven, согласно корневому README.

Старый SQLite-файл в папке `data` сохранён. Пароль и сеансы из прежнего сервера не используются Spring Security.
